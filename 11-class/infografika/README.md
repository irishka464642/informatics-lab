# Інфографіка — практична робота №5 (11 клас)

## Файли
- `index.html` — урок, чотири приклади інфографіки, інструкція, чекліст, критерії оцінювання.
- `constructor.html` — автономний редактор інфографіки. Весь HTML, CSS та JavaScript міститься в одному файлі. Жодних CDN, зовнішніх шрифтів чи мережевих бібліотек.

## Як проводити урок без інтернету
1. **Заздалегідь**, коли є доступ до інтернету, завантажте `constructor.html` на смартфон (із GitHub або кнопкою «Завантажити для офлайн-роботи» на сторінці уроку).
2. Передайте файл учням Bluetooth / Quick Share / кабелем / локальним обміном.
3. Відкрийте `constructor.html` **локально у браузері**. Залежно від пристрою може знадобитися «Відкрити за допомогою» → Chrome, Firefox, Safari чи інший браузер із підтримкою локальних HTML.
4. Створіть інфографіку; збережіть **PNG** для здавання або **SVG**, якщо браузер не підтримує створення PNG з локального SVG. Кнопка «Зберегти проєкт» створює JSON для подальшого редагування.

> Без інтернету GitHub Pages і Canva не відкриваються вперше; автономно працює **завантажений HTML-файл**, а не адреса сайту. У деяких телефонах відкриття локальних HTML-файлів обмежене — перевірте на конкретному пристрої заздалегідь.

Початковий зразок — покроковий алгоритм перевірки інформації без вигаданих статистичних показників. Тема учнівських робіт довільна. У числових діаграмах потрібні справжні перевірені дані, однакова одиниця вимірювання та вказане джерело.
