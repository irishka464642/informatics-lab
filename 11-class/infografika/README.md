# Інфографіка — практична робота №5 (11 клас)

## Що є в папці

- `index.html` — навчальний сайт із прикладами, інструкцією, чеклістом і критеріями.
- `constructor.html` — **автономна майстерня графічного дизайну** для смартфона. Усі стилі, піктограми й скрипти в одному файлі. Після завантаження інтернет не потрібен.

## Можливості конструктора

- 8 готових фонів: однотонні й із візерунками.
- 4 різні композиційні шаблони: журнальний стиль, таймлайн, дашборд, порівняння.
- Текстові блоки, заголовки, великі числа; зміна тексту, кольору, шрифту, розміру, ширини.
- Кола, кольорові блоки, стрілки, 12 векторних піктограм.
- Вставлення власного зображення з пам’яті телефона (PNG/JPG/WebP до 4 МБ).
- Перетягування елементів пальцем, дублювання, видалення, зміна порядку шарів, пересування кнопками.
- Експорт PNG, SVG, збереження/відкриття редагованого проєкту JSON.
- Початок із порожнього полотна; редагований проєкт зберігається та відкривається у форматі JSON.

## Робота без інтернету

1. **До уроку** завантажте файл `constructor.html` із GitHub або через кнопку «Завантажити для офлайн-роботи» на сайті уроку.
2. Передайте файл учням Bluetooth / Quick Share / кабелем або іншим локальним способом.
3. Відкрийте локальний файл у браузері. На деяких смартфонах потрібно вибрати «Відкрити за допомогою» → браузер; деякі пристрої обмежують відкриття локальних HTML-файлів. Перевірте заздалегідь.
4. Додайте фон і елементи, змініть написи, розташуйте їх на полотні, збережіть PNG. Якщо PNG-експорт недоступний у браузері, використайте SVG.

**Увага:** завантажити сайт уперше з GitHub Pages без мережі не вийде; офлайн працює саме попередньо збережений HTML. Великі фотографії можуть перевищувати доступне місце локального сховища. Для продовження роботи радимо експортувати JSON-проєкт.

## Оновлення майстерні

Конструктор відкривається з **порожнім полотном**, без автоматично встановленого шаблону. Для натхнення є 4 різні композиції: **журнальний стиль**, **маршрут/таймлайн**, **інформаційна панель із балами** й **порівняння растру та вектора**. Учні можуть вибрати готовий макет або з нуля створити власний. Кожен макет складається з окремих редагованих об'єктів.

**Увага:** редактор щоразу відкривається з порожнього полотна. Щоб продовжити роботу пізніше, натисніть **«💾 Проєкт»** (збережеться JSON), а на наступному занятті — **«📂 Відкрити проєкт»**. Зображення PNG не зберігає можливість редагування.
