Створи власну інфографіку

Працює без інтернету, Canva та реєстрації. Обирай будь-яку тему, додавай змістовні блоки, змінюй оформлення й завантажуй результат як PNG або SVG. Усі приклади — українською.

2. Інформаційні блоки

Можна додати від 2 до 6 блоків. Для діаграми заповни також числові значення (усі в одних одиницях). Дані мають бути перевіреними.

3. Результат

Без інтернету

PNG — для здавання роботи вчителю. SVG — векторне зображення. Проєкт JSON — щоб пізніше продовжити редагування. Файл експортується на пристрій, а не надсилається в інтернет.

Порада: перед уроком збережи цю сторінку як файл constructor.html на телефоні й відкрий його браузером. Якщо браузер підтримує локальні HTML-файли, конструктор працюватиме без мережі. Не вигадуй статистику: для числових діаграм додавай реальні дані та джерело.
