# Урок 11: Ресурси інтернету для навчання (5 класи)

**Сайт для учнів:** https://irishka464642.github.io/informatics-lab/5-class/2026-11-17/

Учень указує прізвище, ім'я, клас (**5-А / 5-Б / 5-В**), групу (**1 / 2**), вибирає один із варіантів **А / Б / В** і виконує навчальні вправи. Підсумковий тест містить 12 завдань, 4 на кожну з ГР1, ГР3, ГР4.

## Журнал результатів

У наданій учителем папці Google Диска вже є папка **«Урок 11»**. У ній створено Google Таблицю **«Журнал результатів — урок 11 — 5-А, 5-Б, 5-В»**, яка містить:
- **Результати:** один рядок на спробу, ідентифікація, оцінки, відповіді, фільтри.
- **Зведення:** підсумки за трьома класами та двома групами.
- **Пояснення:** призначення журналу та застереження.

Адреса таблиці та персональні дані учнів **не публікуються в GitHub**.

## Підключення автоматичного запису

**Ще не активне.** Для підключення:

1. Відкрийте Google Таблицю журналу через Google Диск.
2. **Розширення → Apps Script**. Вставте код із [Code.gs](./Code.gs) у приватний проєкт, прив'язаний до цієї таблиці.
3. Запустіть функцію **setupJournal** і надайте дозволи.
4. **Deploy → New deployment → Web app**. Запуск від власника (Execute as: Me). Доступ **Anyone** дозволяється лише відповідно до політики закладу.
5. Скопіюйте URL вебзастосунку `/exec` і вставте його в [index.html](./index.html) як значення змінної `RESULTS_ENDPOINT`.
6. Перевірте надсилання на **вигаданих даних** і фактичне створення рядка в журналі.

Без цього підключення учень може **завантажити CSV** з результатом для ручного імпорту. Надсилання електронною поштою відсутнє.

**Безпека:** перед збиранням ПІБ дітей перевірте налаштування доступу до журналу, особливо читання на рівні шкільного домену. Відкритий вебприймач не перевіряє особу учня та може отримувати повторні дані. У режимі `no-cors` браузер не може підтвердити, що запис з'явився в таблиці.

Навчальна основа: КТП і підручник Й. Ривкінда та ін., § 2.1–2.5.
