# Надсилання Word (.docx) на пошту вчителя

У редакторі «Мій Word — 6 клас» є два способи надсилання:

1. **Через поштовий застосунок телефона:** натисніть ✉ → «Відкрити поштовий застосунок із DOCX». Оберіть Gmail / Outlook, введіть адресу вчителя та перевірте вкладення перед надсиланням. Цей режим залежить від підтримки Web Share API. Якщо не працює — завантажте DOCX і прикріпіть його вручну.
2. **Безпосередньо вчителю:** після налаштування Google Apps Script учень вводить код доступу, а лист із вкладенням .docx надсилає поштовий сервіс учителя. У новій вкладці відкривається підтвердження або повідомлення про помилку.

## Одноразове підключення для вчителя

### Крок 1: створіть серверний скрипт

Відкрийте https://script.google.com/ зі свого Google-акаунта → «Новий проєкт». Назвіть його, наприклад, Word6 Submission. Скопіюйте весь вміст файлу [Code.gs](Code.gs) із цієї папки в редактор Apps Script і збережіть.

### Крок 2: налаштуйте приватні властивості

Відкрийте Project Settings → Script properties та додайте:

- WORD6_TEACHER_EMAIL — адреса, на яку отримувати учнівські роботи.
- WORD6_CLASS_PIN — власний пароль доступу щонайменше з 8 символів.

**Не додавайте ці значення до GitHub.** Пароль повідомте учням під час уроку та змініть після уроку.

### Крок 3: розгорніть Web App

Оберіть Deploy → New deployment → Web app.

- Execute as: Me.
- Who has access: Anyone, якщо політика шкільного акаунта це дозволяє.

Підтвердьте дозвіл MailApp на надсилання листів від вашого акаунта. Копіюйте URL вебзастосунку, який закінчується на /exec. Не використовуйте /dev.

**Безпека:** це публічний веб-endpoint, який після правильної авторизації зможе надсилати листи від вашого акаунта. У коді є пароль уроку, єдиний фіксований отримувач і ліміти, але це не повноцінна автентифікація. Якщо публічна форма суперечить правилам закладу, використовуйте лише поштові застосунки учнів.

### Крок 4: увімкніть у GitHub

Відкрийте файл [email-config.js](../email-config.js) в GitHub, натисніть Edit та вставте свій URL /exec у поле endpoint. Наприклад:

    window.WORD6_MAIL = {
      endpoint: "https://script.google.com/macros/s/ВАШ_ІДЕНТИФІКАТОР/exec",
      label: "пошту вчителя"
    };

Збережіть через Commit changes. **Пароль і поштову адресу тут не зазначайте.** URL скрипту не вважається секретом.

### Крок 5: обов'язково протестуйте

1. Відкрийте https://irishka464642.github.io/informatics-lab/word-editor/
2. Укажіть клас і тестовий навчальний код (наприклад T01).
3. Створіть документ із текстом, малюнком і таблицею.
4. Натисніть ✉ → «Надіслати .docx вчителю», введіть пароль уроку.
5. Перевірте **сторінку підтвердження** в новій вкладці, а потім **пошту вчителя** — має надійти лист із вкладенням .docx.
6. Відкрийте вкладення в Word чи LibreOffice та перевірте оформлення.

Поки ці дії не виконані, пряме надсилання **неактивне**. Режим поширення файла через телефон доступний окремо.

## Обмеження

- До **2 МБ** на Word-файл у прямому режимі.
- До **3 відправлень на день** з одного навчального коду і **80 загалом на день**. Також діють квоти MailApp.
- Учень не обирає отримувача у прямому режимі: адреса задається тільки приватною властивістю Apps Script.
- Навчальні коди не є достовірною ідентифікацією учня: їх можна помилково або навмисно переплутати.
- Скрипт не зберігає файл на Google Drive; створює лист із вкладенням та зберігає лише лічильники відправлень.
- Перевіряйте повідомлення у новій вкладці: сам факт натискання кнопки **не доводить**, що лист успішно надійшов.
- У шкільних Google Workspace-акаунтах публічні Web Apps можуть бути заборонені адміністратором.
- Після змін у Code.gs розгорніть нову версію через Manage deployments → Edit → New version → Deploy.
