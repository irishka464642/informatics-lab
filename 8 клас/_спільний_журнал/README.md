# Єдиний журнал результатів ігор — 8 клас

**Один Apps Script для всіх уроків.** На кожну дату скрипт створює у спільній Google Таблиці новий аркуш `ДД.ММ.РРРР`. Дані 8-А, 8-Б і груп 1–2 потрапляють у відповідний аркуш; клас і група є окремими колонками.

## Одноразове налаштування

1. Відкрийте **робочу**, а не особисту Google Таблицю «Інформатика 8 клас — загальний журнал результатів інтерактивних ігор».
2. **Розширення → Apps Script** → скопіюйте в `Code.gs` код із [Code.gs](./Code.gs) → збережіть.
3. **Розгорнути → Нове розгортання → Вебзастосунок**. «Виконувати від імені» — власник таблиці. Надання доступу — згідно з політикою школи. Для телефонів без шкільних Google-акаунтів може бути потрібен режим `Anyone`, якщо його дозволяє адміністратор.
4. Скопіюйте посилання вебзастосунку `https://script.google.com/macros/s/.../exec`.
5. У **кожній** грі один раз вставте цю адресу в `const RESULTS_ENDPOINT = '...';`. **Для наступного уроку Apps Script повторно розгортати не потрібно.**
6. Для нової гри змініть лише `lessonDate`, `lessonId`, `gameTitle`, `taskNo` та параметри завдань.

## Формат JSON, який надсилає будь-яка гра

```json
{
  "apiVersion": 1,
  "lessonDate": "2026-11-20",
  "lessonId": "21-22",
  "gameTitle": "TRUE чи FALSE? Зламай код логіки",
  "klass": "8-А",
  "group": "1",
  "surname": "Приклад",
  "firstname": "Учень",
  "taskNo": "Місія 2 / запитання 1",
  "progress": 3,
  "maxProgress": 12,
  "score": 1,
  "maxScore": 1,
  "firstTry": 2,
  "questionMisses": 0,
  "totalMisses": 1,
  "eventId": "demo-session-abc123-3",
  "sessionId": "demo-session-abc123"
}
```

- `lessonDate` — дата заняття у форматі **YYYY-MM-DD**. Вкладка `20.11.2026` або інша дата створюється автоматично за першого надсилання.
- `eventId` — **унікальний для кожного завершеного завдання**. При повторному запиті з тим самим ID додатковий рядок не створюється.
- `firstTry` — накопичувальна кількість завдань, правильно виконаних без помилок. `progress` не є шкільною оцінкою.
- Для однієї гри на різні класи можна задавати окремі дати, наприклад `8-А → 2026-11-20`, `8-Б → 2026-11-23`.

## Надсилання після кнопки «Наступне завдання»

```js
// Приклад фрагмента коду гри:
fetch(RESULTS_ENDPOINT, {
  method: "POST",
  mode: "no-cors",
  headers: {"Content-Type": "text/plain;charset=UTF-8"},
  body: JSON.stringify(event)
});
```

Використовуйте локальну чергу збереження, щоб у разі втрати інтернету повторити відправку. Режим `no-cors` **не дозволяє браузеру перевірити підтвердження запису**; остаточний результат перевіряється в Google Таблиці.

## Приватність

Вкладки міститимуть ПІБ учнів. **Не відкривайте журнал для публічного доступу** та дотримуйтеся шкільних правил обробки персональних даних. Якщо вебзастосунок працює в режимі `Anyone`, відправник не проходить автентифікацію, а результати потенційно можна підробити. Для офіційного оцінювання потрібна додаткова перевірка.

**Важливо:** Код із GitHub — це вихідний файл, а не вже розгорнутий вебзастосунок. Перший запуск та надання дозволів потрібно виконати у Google Apps Script власником таблиці.
