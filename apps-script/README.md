# Журнали результатів Informatics Lab

Система розрахована на **шість окремих Google Таблиць**:

| Клас | Група 1 | Група 2 |
|---|---|---|
| 6-А | окрема таблиця | окрема таблиця |
| 6-Б | окрема таблиця | окрема таблиця |
| 6-В | окрема таблиця | окрема таблиця |

## Налаштування (вчитель)

1. Увійдіть у потрібний Google-акаунт, відкрийте [Google Apps Script](https://script.google.com/home/start) і створіть проєкт.
2. Скопіюйте код із файлу `apps-script/Code.gs` в редактор Apps Script.
3. Виберіть функцію `setupJournals`, натисніть **Run** і надайте запитані дозволи. Вона створює 6 **окремих** приватних Google Таблиць у цьому обліковому записі. Посилання на них будуть у Execution log.
4. Для кожної таблиці налаштуйте доступ тільки потрібному вчителю. Таблиці та персональні дані не треба публікувати.
5. **Deploy → New deployment → Web app**. Execute as **Me**. Для учнів без Google-акаунтів потрібен доступ **Anyone**. Уважно враховуйте шкільні вимоги до обробки персональних даних дітей: загальнодоступний endpoint приймає непідтверджені записи.
6. Скопіюйте Web app URL, що закінчується на `/exec`. У файлі `index.html` змініть `const RESULTS_ENDPOINT="";` на адресу вебзастосунку. Не додавайте до GitHub приватні посилання на журнали чи списки дітей.
7. Після оновлення GitHub Pages перевірте тестовим записом, що новий рядок з'являється **в правильній таблиці**.

**Увага.** У браузері використовується `no-cors`, тому успішний запит не підтверджує фактичний запис. Сайт зберігає локальну копію; учитель повинен перевірити запис у таблиці. Без налаштованого URL результати залишаються тільки в браузері. Не проводьте тест з реальними ПІБ учнів, доки не перевірите доступ до таблиць.

**Обмеження захисту.** Код вебзастосунку відкритий, а запити не автентифікують особу учня; можливі чужі чи повторні записи. Якщо школа вимагає підтверджений облік або забороняє збір ПІБ через відкриті вебформи, використовуйте псевдонімні коди або захищену систему авторизації замість цього варіанта.
