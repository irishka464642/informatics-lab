## Налаштування (особистий Google-акаунт)

Шість приватних Google Таблиць **вже створено** в папці `Informatics Lab — журнали результатів` на диску `irishka464642@gmail.com`. Не створюйте дублікати.

1. Увійдіть саме в `irishka464642@gmail.com` та відкрийте [Google Apps Script](https://script.google.com/home/start). Створіть новий проєкт.
2. Скопіюйте код із `apps-script/Code.gs` в редактор Apps Script. Публічний GitHub не містить ідентифікаторів таблиць.
3. Виберіть `setupJournals`, натисніть **Run** і надайте дозволи. Функція знаходить **вже створені** шість таблиць у приватній папці, прив'язує їхні ID до Script Properties. Перевірте Execution log.
4. **Deploy → New deployment → Web app**. Execute as **Me**. Для надсилання без Google-акаунтів потрібно ввімкнути **Anyone**. Оскільки учні неповнолітні, перш ніж збирати ПІБ, перевірте шкільну політику захисту даних: такий endpoint публічно доступний і не підтверджує особу.
5. Скопіюйте Web app URL, що закінчується на `/exec`; у `index.html` потрібно буде встановити значення `RESULTS_ENDPOINT`. Не публікуйте приватні журнали та дані дітей у GitHub.
6. Відправте тестові вигадані дані й перевірте правильний журнал; лише після цього використовуйте з класом.

**Увага.** У браузері використовується `no-cors`, тому успішний запит не підтверджує фактичний запис. Сайт зберігає локальну копію; учитель повинен перевірити запис у таблиці. Без налаштованого URL результати залишаються тільки в браузері. Не проводьте тест з реальними ПІБ учнів, доки не перевірите доступ до таблиць.

**Обмеження захисту.** Код вебзастосунку відкритий, а запити не автентифікують особу учня; можливі чужі чи повторні записи. Якщо школа вимагає підтверджений облік або забороняє збір ПІБ через відкриті вебформи, використовуйте псевдонімні коди або захищену систему авторизації замість цього варіанта.
