# Informatics Lab

Інтерактивні вправи з інформатики для 6-А, 6-Б та 6-В класів.

## Перша вправа

**«Наведи лад у таблиці»** — учні читають інформацію про гуртки і заповнюють таблицю (12 клітинок). На смартфоні достатньо натискати картку, потім клітинку; перетягування не потрібне.

## Запуск

Відкрити файл `index.html` у браузері або опублікувати сайт: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Адреса після ввімкнення Pages: https://irishka464642.github.io/informatics-lab/

## Результати й конфіденційність

- Учень обирає клас (6-А, 6-Б або 6-В) та вводить **навчальний код**, не прізвище.
- Перевірки (бал, час, спроба, клас і код) зберігаються **тільки локально** в браузері, якщо пристрій дозволяє localStorage.
- Можна експортувати результати цього браузера в CSV, але на особистих телефонах учитель автоматично їх не бачить.
- **Автоматичний збір у Google Таблицю ще не підключено.** Для нього знадобиться Google Apps Script, приватна Google Таблиця та окреме налаштування доступу. Не публікуйте приватну таблицю в репозиторії.
- Навчальні коди не гарантують ідентифікації: учень може помилково або навмисно ввести чужий код. Список відповідності кодів учням зберігайте окремо вчителю.
- Коли інтернету немає, файл можна відкрити локально на пристрої, якщо браузер дозволяє відкривати HTML.

## Методика

Розминка на 7–10 хв до практичної роботи з таблицями **в текстовому документі**. Ця вправа не замінює опрацювання таблиць у текстовому редакторі.
